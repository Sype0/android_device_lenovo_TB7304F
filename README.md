# LineageOS 14.1 device tree for Lenovo Tab 7 Essential (TB-7304F)

Work in progress: this is a skeleton to prove the build infrastructure, it has
no vendor blobs yet and does not boot.

MediaTek MT8167, stock Android 7.0, 600x1024. Uses the stock 4.4.22 kernel as a
prebuilt because there is no kernel source for this board.
